# QA Testing – TFSA Calculator

This project demonstrates manual testing of the Coast Capital Savings TFSA calculator.

## Testing Approach
Test cases were designed using equivalence partitioning to validate input fields and calculator behaviour.

## Testing Artifacts
- Test cases and execution results
- Two documented bug reports

## Bugs Identified
1. Missing validation message when Gross Annual Income is empty.
2. Generic error message when Contribution Amount exceeds allowed range.

## Skills Demonstrated
- Test case design
- Equivalence partitioning
- Test execution
- Bug reporting
